# My Personal Portfolio

## How was the project developed?

The project was developed by me with the help of Anthropic's artificial intelligence (Claude) using the following languages:

- HTML5
- CSS3
- JavaScript

For the HTML development, a fully semantic language was used for greater accessibility and better SEO
to help Google's algorithm understand and classify my project/website, and to help assistive technologies, such as screen readers, to read and navigate the site logically. People with visual impairments can perfectly understand the page structure.
