# 👨‍💻 My Personal Portfolio

This is my second independent project, built to act as my digital resume/business card and centralize my evolution as a Front-End developer.

## 🎯 About the Project

The main objective of this website is to present who I am, my technical skills, and the projects I have been developing at the beginning of my programming career. It was designed with a special focus on **accessibility**, **responsive design**, and **fluid animations**.

I firmly believe that good code and good design should go hand in hand, providing an intuitive and elegant user experience (UX).

## 🛠️ Technologies Used

The portfolio was built using the following programming languages:

* **HTML5:** Semantic structuring ensuring optimized reading by screen readers and good SEO practices.

* **CSS3:** Modern styling using CSS variables, Flexbox, CSS Grid, Media Queries for full responsiveness. * **JavaScript:** Logic for interface interactions, such as custom cursor, loading screen (loader), and interactive mobile menu.

## ✨ Some Features

* **Responsive Design:** The interface adapts perfectly to mobile devices, tablets, and desktops.

* **Custom Visual Elements:** Custom cursor that interacts with mouse movement and an animated loader on page initialization.

* **Form Integration:** Fully functional contact section operating through the FormSubmit API.

## 🚀 Featured Projects

In this portfolio, you will find links and details about the practical projects I have been developing, including:

1. **SkillMatch JS:** System for analyzing compatibility between candidates and job openings using JavaScript logic.

2. **Landing Pages (Beauty Salon v1 and v2):** Pages focused on animations, responsiveness, and interactivity.

3. **Sítio Três Cascatas:** Landing page developed for a real lodging experience, using immersive design.
